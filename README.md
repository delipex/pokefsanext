# PokéFSA Next

Aplicação web desenvolvida com Next.js e TypeScript.

---

## 💻 Desenvolvimento

```bash
# Instalar dependências
npm install

# Iniciar servidor local
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000).

---

## 📦 Scripts

- `npm run dev` - Executa o ambiente de desenvolvimento
- `npm run build` - Compila a aplicação para produção
- `npm run start` - Inicia o servidor de produção
- `npm run branch:new` - Cria uma branch de desenvolvimento
- `npm run pr:create` - Envia branch e abre Pull Request
- `npm run pr:merge` - Realiza o merge seguro
